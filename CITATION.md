# Citing ai-research-env

If you use **ai-research-env** in research, please cite the specific software release used for the analysis whenever possible.

GitHub reads the repository's [`CITATION.cff`](CITATION.cff) file and exposes formatted citation information through the repository's **Cite this repository** interface.

## v0.1.0

The first citable release is archived on Zenodo with the version-specific DOI:

**10.5281/zenodo.22761575**

Recommended citation:

> Ötleş, E. (2026). *ai-research-env: A reproducible research environment for AI and machine learning* (v0.1.0). Zenodo. https://doi.org/10.5281/zenodo.22761575

For reproducible work, cite the Zenodo DOI associated with the exact ai-research-env release used rather than the moving `main` branch.

When reporting computational methods, also record the release or commit used and, when relevant, the immutable container image tag or digest and lockfile SHA256.

## General project citation

Zenodo also assigns a concept DOI that resolves across all releases. Once that identifier is confirmed publicly, it will be recorded here for citations that refer to the overall ai-research-env project rather than a specific computational snapshot.

The citation metadata is maintained in [`CITATION.cff`](CITATION.cff).
